# rustspeak

I want to create a text and voice communication app like Teamspeak or Discord in Rust.

in first phase. i want following feature first:

- user system = user, auth, role
- text messaging system = in server, and direct message
- voice system = with channel

separate each system with Rust Workspace Member Crates.

we should use webRTC for communication. secure text and voice with tls.

run on web browser first. basic Vue + Bootstrap 5 for frontend.
